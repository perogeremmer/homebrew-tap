# Homebrew tap untuk Hakonfig

Instal CLI Hakonfig dengan:

```bash
brew install perogeremmer/tap/hakonfig-cli
```

Formula `hakonfig-cli.rb` di-update otomatis oleh workflow
`homebrew-tap.yml` di repo [perogeremmer/hakonfig](https://github.com/perogeremmer/hakonfig)
setiap kali sebuah release di-publish (jalankan manual: `gh workflow run homebrew-tap.yml -f tag=vX.Y.Z`).

Aplikasi desktop tidak dipasang lewat Homebrew; unduh dari
[halaman releases](https://github.com/perogeremmer/hakonfig/releases/latest).
